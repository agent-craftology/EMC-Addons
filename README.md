# EMC Addons

Free public Fabric mod for EarthMC: a click GUI, HUD stats cards (sidebar currencies), and config profiles.

This is **not** the paid EMC Bundle. There is no automation.

## Versions

Gradle projects:

- `emcaddons-1.18.2`
- `emcaddons-1.19.4`
- `emcaddons-1.20.6`
- `emcaddons-1.21`
- `emcaddons-1.21.11`
- `emcaddons-26.2`

Default open-GUI keybind: **Right Alt**

## Build

In each subproject:

```bash
./gradlew build
```
